feat(node): standalone Rust node — verified mempool + wallet RPCs

The Rust node is now self-sufficient (no Go simnode needed for txs):

- real SubmitTX: deserialize -> expand CLn/CRn + publickeylist from the
  node's own balance tree -> full bulletproof verify -> mempool
- snapshot-based verification: per-block state snapshots (roothash ->
  trees) so txs referencing a recent state verify correctly even while
  the node mines (the live trees advance every block)
- CheckTxHash RPC
- wallet RPCs: GetEncryptedBalance (from own tree via blake2s pointer),
  GetRandomAddress (32 registered bech32 candidates), GetRegistrations,
  GetInfo with top_block_hash
- --mine-interval-ms flag (default 2000)
- wallet.rs: real BSGS balance decode (decode_balance) — the wallet
  decodes its own encrypted balance with its secret, no daemon wallet
  needed; the differential harness now passes the sender balance
- END-TO-END PROVEN: Rust wallet -> Rust node (proof verified against
  the node's state) -> mempool -> mined by the Rust node -> wdst
  balance moved (10 DERO received). Fully Rust transaction loop.
